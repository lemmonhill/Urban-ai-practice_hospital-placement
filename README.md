# Размещение больниц — Астрахань

Публичная версия: <https://hospital-placement.onrender.com/>

Веб-приложение для оценки размещения новых больниц в Астрахани. Показывает
исходную обеспеченность населения местами в стационарах, считает ручные
сценарии и автоматически подбирает квартал для одной новой больницы.

Приложение работает **без интернета**: Leaflet, улицы и вода хранятся локально.
Внешние картографические запросы не используются.

## Возможности

- карта 4 441 квартала с режимами «Исходное состояние», «Сценарий»,
  «Изменение»;
- карточка квартала: население, потребность, вместимость, обеспеченность,
  дефицит;
- ручной сценарий из нескольких больниц;
- автоматический подбор квартала для больницы заданной вместимости;
- KPI, таблица по кварталам с сортировкой, фильтром и страницами;
- таблица вариантов автоподбора и равноценных лучших кварталов;
- сохранение, загрузка, удаление и сравнение сценариев;
- экспорт результатов по кварталам и автоподбора в CSV;
- проверка исходного расчёта при запуске.

## Быстрый запуск

Из папки `hospital-placement`:

```powershell
& "..\python-package-boilerplate\.venv\Scripts\python.exe" app.py --port 8050
```

При запуске приложение загружает данные и сверяет исходный расчёт с практикой 2,
поэтому старт занимает около 10–15 секунд. Для быстрого старта без
дополнительной сверки BlocksNet:

```powershell
$env:HOSPITAL_PLACEMENT_VALIDATE_BLOCKSNET='0'
& "..\python-package-boilerplate\.venv\Scripts\python.exe" app.py --port 8050
```

Сохранённая обеспеченность всё равно сверяется с векторизованной реализацией.
Проверка готовности:

```powershell
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:8050/api/health
```

Ожидаемый ответ: `{"blocks": 4441, "ok": true}`.

Если нужно создать отдельное окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py --port 8050
```

## Как пользоваться

1. Нажмите на квартал на карте или на строку таблицы.
2. Укажите вместимость новой больницы и нажмите «Добавить в сценарий».
3. Можно добавить несколько больниц, в том числе в разные кварталы.
4. Нажмите «Рассчитать сценарий».
5. Переключайте режимы карты и вкладки результатов.
6. Для автоподбора задайте вместимость и нажмите «Разместить автоматически».
7. Сохранённые сценарии можно сравнить на вкладке «Сравнение сценариев».

Кнопка «Сбросить» возвращает исходное состояние. Экспорт CSV выгружает текущую
таблицу кварталов или полную таблицу автоподбора.

## Быстрая проверка в браузере

1. Открыть <http://127.0.0.1:8050/> и проверить бейдж сверки и KPI: дефицит
   1 546, обеспеченность 75,2%.
2. В фильтре таблицы ввести `321`, нажать на строку квартала, указать 600 мест,
   нажать «Добавить в сценарий», затем «Рассчитать сценарий».
3. Проверить KPI: дефицит 952, сокращение 594, обеспеченность 84,7%.
4. Включить режим «Изменение» и посмотреть зелёные кварталы вокруг 321.
5. Нажать «Разместить автоматически»: должно загрузиться 4 441 из 4 441
   кварталов, лучшее сокращение 594 и 23 равноценных квартала.
6. На вкладке «Варианты автоподбора» проверить сортировку по сокращению
   дефицита, единицы измерения и пагинацию.
7. Сохранить сценарий, открыть «Сравнение сценариев», затем нажать «Сбросить»
   и проверить возврат к дефициту 1 546.

## Данные

Для работы и деплоя используется компактный набор `data/astrakhan_compact/`
(около 40 МБ):

- `accessibility_matrix.npz` — матрица пешеходной доступности `float32`;
- `blocks.parquet` — кварталы и исходная обеспеченность;
- `population.parquet` — калиброванное население;
- `hospitals_blocks.parquet` — существующая вместимость;
- `hospitals.parquet`, `boundaries.parquet` — больницы и граница;
- `roads.parquet`, `water.parquet` — локальная подложка карты;
- `hospitals_provision.parquet` — сохранённый расчёт практики 2;
- `manifest.json` — размеры и контрольные параметры.

Исходные файлы практики 2 не изменяются и не нужны для запуска приложения.
Результаты расчётов, кэш автоподбора и пользовательские сценарии сохраняются в
`data/results/`. Пересобрать компактный набор можно командой:

```powershell
& "..\python-package-boilerplate\.venv\Scripts\python.exe" scripts\build_compact_data.py
```

## Методика

- норматив: 9 мест на 1 000 жителей;
- доступность: 60 минут пешком;
- потребность квартала: `ceil(население / 1000 × 9)` — так же, как в BlocksNet
  практики 2; поэтому сумма по кварталам 6 240, а линейный расчёт от общей
  численности даёт 4 194;
- обеспеченность: конкурентный метод `competitive_provision` BlocksNet;
- сценарии: вместимость выбранного квартала увеличивается, расчёт повторяется
  по исходным населению и матрице доступности;
- автоподбор: все кварталы проверяются независимо через OR-Tools min-cost-flow
  на том же графе доступности и с теми же весами;
- лучшие варианты и ручные сценарии пересчитываются штатной функцией BlocksNet;
- векторизованная LP-реализация на scipy/HiGHS используется для проверок.

Подробные результаты и ограничения — в [REPORT.md](REPORT.md).

## Проверки

```powershell
& "..\python-package-boilerplate\.venv\Scripts\python.exe" -m unittest discover -s tests -v
```

Тесты проверяют компактный набор данных, воспроизведение исходного расчёта,
добавление вместимости, валидацию, неизменность исходных файлов, полный перебор
кварталов, независимость вариантов автоподбора, равноценные лучшие результаты,
API, локальный Leaflet и сохранение сценариев.

Дополнительные скрипты:

```powershell
& "..\python-package-boilerplate\.venv\Scripts\python.exe" scripts\run_auto.py --capacity 600
& "..\python-package-boilerplate\.venv\Scripts\python.exe" scripts\verify_auto.py --capacity 600
& "..\python-package-boilerplate\.venv\Scripts\python.exe" scripts\run_experiment_api.py
```

`run_experiment_api.py` прогоняет сценарии А, Б и В через запущенное приложение
и сохраняет сводку и CSV в `data/results/experiments/`.

```powershell
docker build -t hospital-placement .
docker run --rm -p 8050:8050 -e PORT=8050 hospital-placement
```

## Ограничения

Население кварталов — калиброванная оценка, вместимость части больниц
достроена BlocksNet, доступность учитывается только по пешеходному графу.
Земельный участок, стоимость строительства и градостроительные ограничения не
оцениваются. Одна больница на 600 мест не закрывает весь дефицит территории.
